# Toy Gallery (web)

Next.js + HeroUI frontend for the Toy Gallery monorepo. Talks to the Django backend at [`../api/`](../api/) over the OpenAPI schema generated by orval.

## Development

```bash
npm install
npm run dev    # next dev, http://localhost:3000
npm run build  # static export to ./build
npm test       # vitest
```

The dev server expects the API at `http://localhost:8000` by default; override with `NEXT_PUBLIC_API_URL` in `.env`.

See the [repo root README](../README.md) for the broader monorepo layout and the [`Makefile`](../Makefile) for cross-project commands.
